codelesstraveled.com
====================

Plain HTML, CSS and JS. No build step, no dependencies, no
node_modules — which is also the argument the site makes, so it had
better be true here. Upload the folder; that's the deploy.

  index.html        the page (contours are inlined into it)
  styles.css        palette and layout live in :root at the top
  main.js           draws the l of "less" as the fork
  tools/contours.py regenerates the terrain
  shots/            project screenshots
  favicon.svg       the mark
  contours.svg      last generated terrain, for reference
